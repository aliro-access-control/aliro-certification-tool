# CSA Aliro Test Harness contribution

This guide indicates how to contribute to this github project. 

## CSA membership
Participants to this github project must be registered as member of the Connectivity Standards Alliance (https://csa-iot.org).
Once registered, you will get access to Causeway: https://groups.csa-iot.org

## Test Harness tiger team
All activities are coordinated in the Aliro Test Harness Tiger Team.
https://groups.csa-iot.org/wg/members-all/workgroup/home, select "members-all > members > aliro-wg > aliro-csg > Aliro CSG Test Harness Tiger Team".
The Tiger Team will have a (weekly) meeting, check the calendar for scheduled time.
In this meeting, the issues are discussed and assiged to individuals.

## Github instructions
When an issue is assigned, contributors need to open a Pull Request to fix the issue if this is code related.
First create a branch (e.g. open the Issue and click the Create a branch link on the right pane).
Once code modifications are done, commit these to the branch and create a new Pull Request.
From the Pull Requests tab, click "New pull request" and modify the "compare" branch to your created branch. Then create the Pull Request.
The issue will then be discussed in the weekly Tiger Team meeting which will assign reviewers to the issue.

## Reviews
Reviewers are requested to review the code, but it is highly recommended to also test the changes if possible.
Once a review is done, the reviewer should indicate the result in the Issue, so the Pull Request can be merged to the main.
The merge will be decided during the Tiger Team meeting: if a Pull Request has 2 independant positive reviews, it will be merged in. 
Exceptionally, a merge can also be done with 1 positive review and no objection by the group during the meeting (typically done for smaller changes).
